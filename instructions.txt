How to build:

1. Open a terminal in the project folder.
2. Run:
   make

This creates the executable:
   cvmpp

How to run a program from a file:

   ./cvmpp program.cvm

How to print the generated bytecode:

   ./cvmpp --disassemble program.cvm

How to trace execution on the virtual machine:

   ./cvmpp --trace program.cvm

How to do both:

   ./cvmpp --disassemble --trace program.cvm

Example calculator program:

   let a=10;
   let b=20;
   print (a+b)*2;
   print a<b;

Example truth-machine style program:

   let x=input;
   if(x==0){
       print 0;
   }else{
       print 1;
   }

Note:
- The compiler converts source code into bytecode.
- The virtual machine executes the bytecode.
- The --disassemble flag shows the bytecode.
- The --trace flag shows step-by-step VM execution.
