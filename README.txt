Project Overview
----------------
CVM++ is a small programming language implemented in C++.

The project includes:
- Lexical Analysis (Lexer)
- Recursive Descent Parsing
- Abstract Syntax Tree (AST)
- Bytecode Generation
- Stack-Based Virtual Machine (VM)

The language supports:
- Integer values
- Boolean values
- Arithmetic operations (+,-,*,/)
- Comparison operations (==,<)
- Variables and assignment
- if / else statements
- while loops
- Dynamic input using input
- Output using print

Build Instructions
------------------

Requirements:
- C++17 compiler
- MSYS2 UCRT64 environment (Windows)
- g++
- mingw32-make

Build Steps:
1. Open MSYS2 UCRT64 terminal.
2. Navigate to the project folder.

Example:
    cd /c/Users/YourName/Desktop/cvmpp

3. Build the project:

    mingw32-make

This creates the executable:
    cvmpp.exe

Running Programs
----------------

Run a CVM++ source file:

    ./cvmpp calculator.cvm

Show generated bytecode:

    ./cvmpp --disassemble calculator.cvm

Show VM execution trace:

    ./cvmpp --trace calculator.cvm

Show both bytecode and trace:

    ./cvmpp --disassemble --trace calculator.cvm

Language Features
-----------------

1. Variable Declaration

    let x=10;

2. Arithmetic

    print 2+3;
    print 10-4;
    print 6*7;
    print 20/5;

3. Comparison

    print a<b;
    print a==b;

4. Input

    let x=input;

5. if / else

    if(x==0){
        print 0;
    }else{
        print 1;
    }

6. while loop

    while(i<5){
        print i;
        i=i+1;
    }

Compiler Pipeline
-----------------

The complete execution flow is:

Source Code
    ->
Lexer
    ->
Tokens
    ->
Parser
    ->
AST
    ->
Bytecode Compiler
    ->
Virtual Machine
    ->
Program Output

Virtual Machine
---------------

The VM is stack-based.

Main VM Components:
- Instruction Pointer (IP)
- Operand Stack
- Global Variable Table
- Bytecode Dispatch Loop

Supported Bytecode Instructions:
- CONSTANT
- ADD
- SUBTRACT
- MULTIPLY
- DIVIDE
- NEGATE
- EQUAL
- LESS
- GET_GLOBAL
- DEFINE_GLOBAL
- SET_GLOBAL
- JUMP_IF_FALSE
- JUMP
- LOOP
- PRINT
- INPUT
- RETURN

Trace Mode
----------

Trace mode displays:
- Current instruction pointer
- Current opcode
- Current stack state

Example:

    ./cvmpp --trace calculator.cvm

This helps visualize VM execution step-by-step.

Disassembler
------------

The disassembler prints generated bytecode in readable form.

Example:

    ./cvmpp --disassemble calculator.cvm

Example output:

    0000 CONSTANT 0 -> 10
    0003 CONSTANT 1 -> 20
    0006 ADD
    0007 PRINT
